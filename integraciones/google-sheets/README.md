# Integración con Google Sheets:
Para la integración con google sheets se necesitan dos cosas:
1. Cuenta de servicio con clave de acceso generada.
2. Google Sheets API habilitada.

Todas las tareas se realizan desde [Consola de Google](https://console.cloud.google.com/welcome/new).
Además, para esto se require tener creado un proyecto en la consola cloud de google.
